# FocusLock — Productivity Tool for Focus Enhancement

## About the App

**FocusLock** is a productivity tool that helps you stay focused on important tasks by temporarily blocking distracting apps on your device.

The app implements the **Pomodoro technique**: you set a timer for a desired period, and FocusLock automatically blocks selected apps until the time runs out.

## Key Features

- **Blocking Timer** (0–90 minutes) — customize the session duration according to the Pomodoro method.
- **Flexible Blocking** — choose which apps to block during your work session.
- **User‑Friendly Interface** — intuitive design for quick session start.
- **Visual Timer Indicator** — monitor the remaining blocking time in real time.
